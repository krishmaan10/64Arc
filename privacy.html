Contact

Privacy note

Short, because we collect very little.

What we collect

For enquiries, we collect what you type into the contact form: your name, company, email, and optionally phone, role, sector and a description of what you are trying to solve.

Why we collect it

We use contact-form details to reply to your enquiry and, if it goes further, to have an informed conversation about your business. The separate PathWay practice-sharing purpose is described below.

Who sees it

The people at 64ARCS involved in responding to you. We do not sell, rent or share enquiry details with third parties, and we do not add you to a marketing list without your asking.

How long we keep it

For as long as the conversation is active, and a reasonable period afterwards for our own records. Ask us to delete it and we will.

64Griddle pilot

The browser pilot at 64arcs.com/64griddle makes no network requests and loads nothing from outside this site. It reads only the text box you are editing, and the checks run on your device; your prompt is not sent anywhere by it. Reference links open the source documentation in a new tab, and your prompt is not included in that request.

The browser extension stores only your preferences and per-site choices, in the browser’s own extension storage. It does not change what the host website does: a site whose prompt box you are editing can still process its own text fields exactly as it did before, under that site’s own privacy terms.

The separately installed macOS companion for native prompt boxes needs Accessibility access to read the box you select; that is a different data path, and the pilot page describes it.

PathWay practice pilot

The public PathWay pilot keeps drafts, saved references, activity and settings in this browser’s local storage. Its replies are prepared examples. It is a prototype: use practice text, not real student records.

Request sharing is off until you enable it in Learning activity. If enabled, subsequent chat requests, the system’s decisions, timestamps, project identifiers and a random browser contributor identifier are sent to the 64ARCS learning collector hosted on Google Cloud. The development operator can read these records to review and improve the request classifier. Saved drafts and replies are not included in the contribution, but names or draft text pasted into a chat request are included. Requests recognised as wellbeing messages have their text removed from the learning record; this automated filter can miss personal information.

Stopping sharing clears the waiting queue and stops future contributions. It does not delete records already sent. “Start again” clears this browser’s pilot state, not server copies. This prototype does not yet provide an automatic retention schedule or a self-service server deletion control. For an existing contribution, contact hello@64arcs.com before resetting the browser, so we can discuss locating the record. Do not assume a local reset removes a remote contribution.

No practice message alerts a teacher or creates a monitored support request. Opening a reference link contacts the source website, whose own privacy terms apply. The separately installed local development server has different data paths, including an optional external model connection; its interface and repository describe them.

Cookies and tracking

This site sets no tracking or advertising cookies. Web fonts are loaded from Google Fonts, which means your browser makes a request to Google's servers when the page loads. We are moving these to our own server so that request stops happening.

Your rights

You can ask what we hold about you, ask for it to be corrected, or ask for it to be deleted. Write to hello@64arcs.com and we will act on it.

Changes

If this note changes materially, the updated version appears here.
