USING 64GRIDDLE

Choose, compare, and apply edits.

  1. Write your prompt. Local rules look for vague requirements, missing task details, repetition, and conflicting instructions.
  2. Confirm the task. Check the detected task type and choose your priority. Agent settings are optional.
  3. Choose your edits. Apply an individual suggestion, or check “Include in preview.” Writing a missing detail selects that detail; you can uncheck it.
  4. Compare and use. Review the original and proposed text, edit the preview, then copy it or replace your draft. 64Griddle never sends it to an agent.

This prototype uses local rules and only reads the current textbox. Open “Why this suggestion?” for the trigger and supporting principle. It cannot judge earlier messages, read attachments, or guarantee a better result. Token counts are approximate.

HOW THE REVIEW WORKS

Useful guidance. Visible reasoning.

Local rules look at the task, explicit requirements, and wording in this textbox. They suggest details to consider—not facts about your project.

  1. Task first. Building, debugging, research, writing, summaries, and data analysis have different checks. You can correct the detected task.
  2. You supply the facts. We do not invent names, deadlines, technologies, or requirements. Suggested workflow wording is optional.
  3. Evidence is inspectable. Each suggestion shows what triggered it. The references below support the general principles; they do not prove that a particular edit will improve a model's answer.

Guidance reviewed 8 September 2026. These checks have not been evaluated for improved model outcomes. Test your prompt against your actual task criteria. Links open the original documentation in a new tab; your prompt is not included.

CHROME / EDGE

Use 64Griddle in browser text fields.

The extension and the Mac companion are part of a pilot by arrangement; this page is the browser workspace on its own. Ask about a pilot ↗

  1. Unzip the download.
  2. Open your browser’s Extensions page and turn on Developer mode.
  3. Choose Load unpacked and select the extension folder containing manifest.json.
  4. Focus a prompt field on a supported site. On another site, use the extension’s toolbar button.

Configured for ChatGPT, Claude, Perplexity, Gemini, Bolt, and Lovable. Live provider editors are not yet certified. The extension stores only preferences and site choices. Host websites can still process their own text fields.

macOS desktop companion

For native prompt boxes, try the local macOS app. Grant Accessibility access, select one app, and enable review. Badge attachment is confirmed in Codex; editing and undo are still under test.
