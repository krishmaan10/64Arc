What 64ARCS has built, and where each piece stops.

Customer software in daily use since July 2026 shows how AI and ordinary rules can help with orders, account summaries and follow-ups alongside existing accounting software. PathWay AI and 64Griddle are separate products, available as browser pilots since September 2026. Each example below describes what it does and its limits.

Help with orders and follow-ups, inside the working day.

At a parts distributor, staff take orders from speech or paper, check account details on a phone and work through overdue accounts. These features have been in daily use since July 2026. The existing accounting software still prices and bills the orders.

Model

Turn an order into editable lines

A model reads a photographed slip or a spoken order, including mixed Hindi and English, and matches the items to the stock catalogue. Staff can check the proposed lines against the attached photograph before sending the order.

The branch receives an import file that opens in its existing accounting software. That software applies its own prices and refuses the same file a second time.

Model

Summarise an account on its screen

A short brief puts the account position into English, Hindi or Marathi. If the model cannot respond, a fixed template provides the summary in the same place.

The brief helps staff read the account; the underlying figures remain available for checking.

Rule

Order the collection follow-ups

A defined calculation sorts the collection list using amounts owed, days overdue, credit limits and recent cheque returns. Accounts already touched that day leave the list.

The ranking follows those agreed rules and needs no language model.

PSS ONE remains a separate pilot: since 28 August 2026, one terminal has read one branch’s books with read-only access; it has never written a real branch’s books.
